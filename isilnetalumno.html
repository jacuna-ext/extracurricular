Objetivo del proyecto (PRY147)

Mejorar el control y la organización de inscripciones a actividades (talleres / eventos / clubes) porque hoy muchos estudiantes se inscriben pero finalmente asisten pocos. Este módulo busca asegurar un flujo claro: publicación → inscripción → control (aforo / cruce / estado académico) → asistencia (talleres) → certificado.
